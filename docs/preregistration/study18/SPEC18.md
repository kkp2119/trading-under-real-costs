## 0. 질문 세 개
- **Q1 (예측):** 결정 시점의 호가 잔량 불균형과 시장 상태로, **다음 중간값 움직임이 우리에게 불리할지**를 처음 보는 종목에서도 맞힐 수 있는가?
- **Q2 (평균 비용):** 그 예측으로 "지금 살지 / 더 기다릴지"를 정하면 E*보다 싼가?
- **Q3 (최악의 경우):** 최악 5% 주문의 비용(95번째 백분위 IS)이 E*보다 낮아지는가? 이것은 E*의 약점(p95 19.4¢ vs 시장가 12.6¢)을 겨냥한다.

**배경:** 큐 불균형은 다음 가격 움직임을 예측하는 신호로 알려져 있다(수업 추천 도서 Cartea, Jaimungal & Penalva의 volume imbalance). 다만 우리 종목처럼 스프레드가 여러 틱인 종목에서는 예측력이 약할 수 있다. 그래서 효과 크기를 미리 단정하지 않는다.

## 2. 주문 설계와 비용 (연구 17과 같음)
- 종목·일당 부모 주문 20건, 1,000주, 기한 300초, 방향 결정 방식도 같다.
- 비용: 시장가 0.3¢/주, 지정가 0
- **체결 가정:** L3D1(주, 가장 엄격), L0D0(보조)
- **비교 대상:** S0(시장가), S1(TWAP), S2i(단순 대기), E*, C3(연구 17의 스프레드 전환)

## 3. 예측 모델 (데이터를 보기 전에 고정)
- **결정 시점:** E*와 같은 5초 간격. 부모 주문에 남은 수량이 있을 때만 쓰고, 기한 시점은 뺀다.
- **입력 4개:** 모두 결정 막대 끝까지의 정보만 쓴다.
  1. 부호 붙인 불균형: (매수 잔량 − 매도 잔량) / (합)을 매수 주문 기준으로 계산한다. 매도 주문은 부호를 뒤집는다. 양수 = 가격이 우리에게 불리하게 갈 압력이다.
  2. 스프레드(틱 수, 10에서 자름)
  3. vol_pre (연구 16-E 정의). 정의할 수 없으면 학습 구간 중앙값을 쓴다.
  4. 직전 5초 중간값 변화(틱, 부호 붙임)
- **목표값 y:** 결정 시점 뒤 첫 중간값 변화가 불리한 방향이면 1, 유리하면 0이다.
  - 60초 안에 변화가 없으면 학습과 예측 채점에서 뺀다. 규칙에는 그대로 적용한다.
- **모델:** 표준화한 로지스틱 회귀, L2 C = 1.0 고정. 학습 구간에서 한 번만 적합하고 계수를 동결한다.
- **예측 평가 지표:** AUC, 0.5 기준 적중률, Brier와 기준률 대비 Brier skill score, 10분위 보정표

## 4. 실행 규칙 후보 (p = 불리한 움직임 예측 확률)
| 번호 | 이름 | 규칙 |
|---|---|---|
| R0 | E* | 동결 규칙 그대로 (기준) |
| R1 | 조기 체결 | E* + 결정 시점에 p ≥ p_hi이면 남은 수량을 그 막대 끝 호가에 시장가로 처리(L3D1이면 D1 벌점) |
| R2 | 대기 유지 | E*의 좁은 스프레드 즉시 체결 조건이어도 p ≤ p_lo이면 건너뛰고 계속 기다린다 |
| R3 | 둘 다 | R1 + R2 |

- **기준값 격자 (고정):** p_hi ∈ {0.60, 0.65, 0.70, 0.75}, p_lo ∈ {0.30, 0.35, 0.40}
  - 후보 수: R1 4개, R2 3개, R3 12개, 합계 19개
- **선택 규칙:** 검증 구간(2019–2020, L3D1) 평균 IS가 가장 낮은 후보를 A*로 정한다.
  - 0.02¢ 안의 동률이면 p95가 낮은 쪽, 그다음 발동 비율이 낮은 쪽을 고른다.
  - A* = R0이면 Q2·Q3는 "개발에서 개선 없음"으로 끝내고, 봉인 검정은 H1만 한다.
- **엔진 확장 테스트:**
  - 합성 테스트: 매수·매도 부호, 기준값 경계, 조기 체결 가격과 D1 벌점
  - 회귀 테스트: R0가 연구 16-D·17의 E* 개발 값을 소수 3자리까지 재현해야 한다.

## 5. 봉인 테스트 가설과 판정 (한 번만 실행)
- **H1 (예측):** 봉인 AUC > 0.5
- **H2 (평균):** A* − E* < 0 (L3D1, ¢/주)
- **H3 (최악의 경우):** p95(A*) − p95(E*) < 0 (L3D1)
- **검정:**
  - 일 단위 순환 블록 부트스트랩, 블록 21일, 10,000회, seed 18
  - 단측, H1~H3에 Holm 보정 (0.0167, 0.025, 0.05)
  - 판정: 보정된 한쪽 신뢰한계가 기준(0.5 또는 0)을 넘으면 "확인"
- **보조 (판정 아님):**
  - L0D0 결과
  - A* − S0, A* − C3, A* − S2i
  - 연도별 결과와 연도별 AUC, 보정표
  - 3 × 3 칸 분해
  - 보통주만 결과
  - **지연 점검:** 결정은 막대 t, 실행은 막대 t+1 호가(1초 늦게). 느린 트레이더도 이 신호를 쓸 수 있는지 본다.
- **검정력:** 봉인 데이터를 열기 전에 검증 구간의 일 단위 분산으로 H2·H3의 MDE를 계산한다. MDE가 검증 구간 효과보다 크면 "검정력 부족"으로 미리 표시한다.
