## 3. 예측 변수와 목표값
- **예측 지점 (경로와 무관):** 각 부모 주문의 도착 시점부터 5초 간격으로 t = 0, 5, …, 295초, 60개 지점을 쓴다. 기한 시점(300초)은 뺀다.
  - 시장 데이터는 우리 주문의 영향을 받지 않는다고 가정하므로, 특징값과 y는 전략 경로와 상관없이 정해진다.
  - 그래서 모델 학습과 예측 채점(H1)은 이 격자 전체를 쓴다. 체결 여부와 관계없이 모든 지점이다.
  - 실행 규칙(R1~R3)은 그 시점에 남은 수량이 있을 때만 p를 쓴다.
- **도착 지점(t = 0)은 포함한다.** E*가 도착 때 좁은 스프레드면 바로 체결하므로, R1·R2가 거기서도 작동해야 한다.
- **목표값 y (1초 막대 끝 중간값 기준):** 결정 막대 끝 중간값과 그 뒤 막대들의 끝 중간값을 차례로 비교한다. 처음 달라지는 막대의 방향으로 정한다.
  - 매수 주문은 위로 가면 1, 매도 주문은 아래로 가면 1이다.
  - 한 막대 안에서 여러 번 바뀐 것은 보지 않는다. 60개 막대 안에 변화가 없으면 학습과 채점에서 뺀다.
- **입력값 시점:**
  - 불균형, 스프레드, 직전 5초 중간값 변화는 결정 막대 끝 값을 쓴다. t = 0의 직전 5초 변화는 도착 전 5초 동안의 변화다.
  - vol_pre는 도착 시점에 한 번 계산하고(연구 16-E 정의), 그 주문의 모든 지점에 같은 값을 쓴다.
- **잔량 열 (bsz/asz):**
  - 이 열이 NBBO를 낸 거래소 하나의 잔량일 수 있다는 점을 WRDS 변수 설명에서 확인해, 그 출처를 `SPEC18_ANSWERS.md` 끝에 적는다.
  - 확인 결과와 관계없이 이 열로 불균형을 계산한다. L3 체결 가정도 같은 열을 쓰기 때문이다.
  - 한계는 보고서에 "최우선 호가를 낸 거래소의 잔량 기준 불균형"이라고 적는다.
- **표준화:** 평균과 표준편차는 학습 구간(2015–2018)에서만 계산해 동결한다.

## 4. 판정 방식
- **Holm 3단계:**
  - p값은 부트스트랩 단측 p값이다. 작은 순서로 0.0167, 0.025, 0.05와 비교하고, 처음 실패한 곳에서 멈춘다.
  - 각 가설의 신뢰한계는 그 가설이 검정된 α의 단측 한계로 보고한다. 예를 들어 0.0167이면 98.33% 한계다.
  - 참고용으로 보정 전 단측 97.5% 한계도 함께 적는다.
- **H1 AUC:** 봉인 격자 지점 전체로 계산한 AUC다. 부트스트랩은 일 단위 블록으로 한다.
- **H3 p95:** 봉인 구간 전체 부모 주문의 IS(¢/주)를 모아 95번째 백분위를 구한다. numpy 기본 선형 보간을 쓴다.
  - 차이는 p95(A*) − p95(E*)다.
  - 부트스트랩 반복마다 다시 뽑은 날들의 주문으로 두 값을 새로 계산해 차이를 구한다.
- **지연 점검 (보조, 판정 아님):**
  - A*와 E* **둘 다**에 적용한다. 결정은 막대 t 정보로 하고, 모든 행동(지정가 주문, 좁은 스프레드 체결, 조기 체결)은 막대 t+1 호가로 실행한다.
  - 보고할 값: A*_지연 − E*_지연(평균과 p95)을 L3D1과 L0D0으로. 2단계 검증 구간에서도 같은 값을 참고로 보고한다.

- **18 R2:**
  - "좁은 스프레드 즉시 체결"은 E1(스프레드 ≤ 2¢)이다.

  - E1이 참인 결정 시점마다 다시 판단한다.
- **19 R3·경계:** p_lo < p_hi라 두 조건은 동시에 참일 수 없다. 경계는 원문대로 ≥ / ≤(같음 포함)다.
- **20 발동 비율:** 부모 주문 가운데 규칙이 E*와 다른 행동을 한 번 이상 한 주문의 비율이다. R1은 조기 시장가, R2는 E1 건너뛰기, R3는 둘 중 하나다.
- **21 H1 단측 p:** 부트스트랩 AUC ≤ 0.5인 비율이다. 일 블록 21일, 10,000회, seed 18.

- **26 검정력 표시:** H3의 MDE는 보수적 환산(일수만 비례)을 쓴다. "검정력 부족" 표시는 2단계에서 A*의 검증 구간 효과가 나오면 H2·H3 모두 확정한다.

## 부록 B. 잔량 열(bsz/asz)의 출처 (Claude, 2026-11-06)
- **WRDS:**
  - 데이터베이스 카탈로그에는 taqm_2021.complete_nbbo_20210104 열 설명이 비어 있다(col_description, obj_description 모두 NULL, 2026-11-06 확인).
  - WRDS 웹사이트의 변수 설명은 로그인이 필요해 이 환경에서는 열지 않았다.
  - 그래서 WRDS가 쓰는 원자료 명세를 출처로 삼는다.
- **NYSE Daily TAQ Client Specification v3.3** (2020-05-20), 5절 "Daily TAQ NBBO File", 29–30쪽. https://www.nyse.com/publicdocs/nyse/data/Daily_TAQ_Client_Spec_v3.3.pdf
  - 5절 도입: "The Daily TAQ NBBO file is a record of all quotes that cause the NBBO to change. The file shows the exchange and quote that caused the change and also provides the NBBO and the exchange(s) that is/are currently setting the NBBO."
  - 같은 곳: "if a quote sets both the National Best Bid and the National Best Offer, that quote is not included in the Daily TAQ NBBO file. These records are found in the TAQ Daily Quote file …"
  - 필드 16 "Best Bid Exchange — The Exchange associated with the Best Bid"
  - 필드 17 "Best Bid Price — The Best Bid Price on a consolidated basis"
  - 필드 18 "Best Bid Size — The Bid Size associated with the Best Bid Price on a consolidated basis, in units of trade"
  - 필드 21–23은 Best Offer에 대한 같은 정의다.
- **해석:**
  - 레코드에는 최우선 매수 거래소가 하나 적히고, 잔량은 "최우선 매수가에 연결된 잔량"이다. 명세 어디에도 같은 가격의 여러 거래소 잔량을 합친다는 말은 없다.
  - 매수·매도 최우선을 한 호가가 동시에 정하는 경우 WRDS complete_nbbo의 행은 Quote 파일에서 온다. 그때 잔량은 그 호가(한 거래소)의 잔량이다.
  - 따라서 bsz/asz는 **최우선 호가를 낸 거래소의 잔량**으로 본다. 다만 이것은 명세 문구에서 끌어낸 해석이고, "합산하지 않는다"는 문장이 명시돼 있지는 않다.
  - WRDS의 best_bidsizeshares는 이 값을 주식 수로 나타낸 것이다(연구 12 SPEC U1).
- **적용:** 답변 3절대로 이 열로 불균형을 계산한다. 보고서에는 "최우선 호가를 낸 거래소의 잔량 기준 불균형"이라고 적는다.
