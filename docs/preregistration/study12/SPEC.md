## 1. 질문, 귀무가설, 기준 샤프, MDE, 검정력
- **질문(주 판정)**: 6절의 규칙으로 선택된 후보 설정이 **대기열 모델(Q, θ = 1)과 실제 비용(R)에서** 홀드아웃(2021-01 ~ 2026-09) 일간 순손익 기준으로 경제적으로 의미 있는 샤프를 내는가.
- **검정 대상**: 후보 설정의 홀드아웃 일간 순손익(달러, 종목 합)으로 계산한 연율 샤프 SR(무위험이자율 없이). **H0: SR ≤ 0. H1: SR > 0. 경제적 기준 SR\* = 0.5.**
- **주기와 검정력**: 연율 샤프의 오차는 일수가 아니라 연수로 정해진다(SE ≈ √((1 + SR²/2) / 연수)). 검출 가능한 최소 샤프(MDE, 80% 검정력, 95% CI) = √(7.84 / (연수 − 3.92)).
  홀드아웃 5.72년: **MDE 2.09**. 개발 2.00년은 3.92년 미만이라 80% 검정력으로 확인 가능한 샤프가 없다(탐색용으로만 쓴다).
- **판정 문턱(5.72년, 정규 근사)**: (a)는 CI 하한 > 0이라 점추정이 약 **1.0**을 넘어야 한다. (b)는 CI 상한 < 0.5라 점추정이 약 **−0.34** 미만이어야 한다.
  | 진짜 샤프 | P(a) | P(b) | P(c) |
  |---|---|---|---|
  | −2.0 | 0.000 | 0.989 | 0.011 |
  | −1.0 | 0.000 | 0.900 | 0.100 |
  | −0.5 | 0.000 | 0.639 | 0.361 |
  | 0.0 | 0.008 | 0.204 | 0.787 |
  | 0.5 | 0.128 | 0.029 | 0.844 |
  | 1.0 | 0.496 | 0.004 | 0.499 |
  | 2.0 | 0.915 | 0.001 | 0.085 |
  | 3.0 | 0.979 | 0.000 | 0.021 |
  (정규 근사 몬테카를로 40만 회, 독립 재계산으로 확인. 합성 테스트 M9에서 블록 부트스트랩으로 재확인.)
  해석: 시장조성은 엣지가 있으면 샤프가 크고(2 이상) 홀드아웃에서 확인될 확률이 높다. 진짜 샤프가 0 근처이면 (c)가 약 79%다.
- **선택 편향**: 후보는 개발 구간에서 격자 중 최고로 뽑히므로 개발 샤프는 낙관적이다. 홀드아웃은 후보 하나만 보므로 판정은 이 편향을 받지 않는다. 낙관 정도는 개발 샤프와 홀드아웃 샤프의 차이로 보고한다.

## 2. 데이터와 종목
### 2.1 막대 데이터
- **원천**: WRDS TAQ 밀리초(taqm_YYYY)의 `complete_nbbo_YYYYMMDD`(NBBO 갱신)와 `ctm_YYYYMMDD`(체결). 종목·일마다 받아 메모리에서 1초 막대로 줄이고 막대만 저장한다.
  저장: `$DATA_DIR/research12_data/{bars_1s_dev, bars_1s_holdout, bars_1s_reserve}`(ETF), `{…_stocks}`(주식). Desktop·iCloud 밖, 클라우드 복사 없음(라이선스 확인 전). 폴더마다 MANIFEST.tsv(행 수, sha256, 마지막 체결 초, 제외된 체결 수의 코드별 집계), `skipped_absent.tsv`(그날 mastm에 종목이 없는 날).
- **1초 막대(정규장 09:30:00 ≤ t < 16:00:00, 23,400행, 21열, int32, 가격 1e-4 달러)**: 막대 u는 [09:30:00 + u, +1초)이다.
  | 열 | 정의 |
  |---|---|
  | bid, ask, bsz, asz | 그 초 마지막 유효 NBBO 상태(없으면 직전 값 이월, 첫 갱신 전 0). **bsz·asz는 주식 수**(U1 완료, LOT_FACTOR = 1, 근거 `best_bidsizeshares`·`best_asksizeshares`) |
  | bid_max, bid_min, ask_max, ask_min | 그 초 안 극값(초 시작 이월 상태 포함) |
  | n_upd, n_xl | NBBO 갱신 행 수, ask ≤ bid인 행 수 |
  | vol, ntr | 유효 체결 수량 합, 건수 |
  | px_last, px_min, px_max | 유효 체결 가격(없으면 0) |
  | vol_bid, vol_ask | 직전 NBBO(엄격히 앞선 마지막 갱신)의 bid 이하 / ask 이상에서 체결된 수량(잠금 호가 가격의 체결은 bid 쪽) |
  | vol_in, vol_unc | 스프레드 안 체결 수량, 직전 NBBO 없는 체결 수량. **vol = vol_bid + vol_ask + vol_in + vol_unc** |
  | vol_bid_odd, vol_ask_odd | vol_bid·vol_ask 중 tr_scond에 `I`(단주)가 있는 체결의 수량 |
- **유효 호가**: qu_cond = 'R', 가격·수량 > 0, **ask ≥ bid**(잠금 포함). ask < bid는 상태·극값에서 제외하고 n_xl에 센다. natbbo_ind가 NBBO 없음을 뜻하는 값(CTA `O`, UTP `1`)은 제외.
- **유효 체결**: tr_corr = '00'이고 tr_scond의 모든 문자가 `@`, `F`, `I`, 빈칸 중 하나. 그 밖은 제외하고 코드별로 센다. 개장·종가 경매 체결은 막대에 들어가지 않는다.
- **NULL 처리(A3, 2026-10-27)**: 호가 행의 가격·수량이 NULL이면 무효 행(직전 유효 상태 이월). 체결 행의 가격·수량이 NULL이면 제외하고 'NULL'로 센다. tr_scond NULL은 빈칸, tr_corr NULL은 '00'이 아니므로 제외('corr=NULL'로 셈). time_m_nano NULL은 그 종목·일을 실패로 기록한다. 정규장 호가 NULL이 한쪽 호가 없음을 뜻하면 이월이 낡은 호가를 남길 수 있다는 한계가 있다(종목·일별 NULL 수를 기록).
- **동시각 처리**: 같은 나노초의 호가는 체결 분류에 쓰지 않고, 초 말 상태와 극값에는 넣는다.
- **캘린더(U2 완료)**: research12/calendar.csv, 2019-01-02 ~ 2026-10-23의 1,964 거래일(그날 ctm 테이블이 있는 날)과 조기 마감 13:00 15일. 조기 마감 목록은 NYSE 규칙에서 옮긴 것이라, 모든 막대를 받은 뒤 MANIFEST의 마지막 체결 초와 대조해 불일치를 checks에 보고한다. 2025-01-09(휴장, 테이블 없음)는 빠져 있다. 2026-02-24는 complete_nbbo가 없어 막대가 없다(건너뛴 날로 세고 보고).
- **날짜 처리**: 그날 mastm에 종목이 없으면 파일을 만들지 않고 skipped_absent에 적는다(상장폐지·합병·종목 코드 변경 포함). 마스터에는 있는데 데이터가 없는 날(정지 등)은 0 막대로 두고 MANIFEST로 구별한다. 종목이 다시 나타나면 그날부터 다시 거래한다.
- **쓰지 않는 것**: 호가 깊이(최우선 이외), 거래소별 호가, 옵션·내재변동성, 시간외 거래.

## 4. 전략 (기본 설정 B0와 변형)
종목 i마다 다음을 한다. 단위: 가격 1틱 = 100(1e-4 달러), 수량은 주.
- **의사결정**: 확인 주기마다(d = d₀, d₀ + Δ, …) 막대 d까지의 정보만 쓴다(룩어헤드 없음). 주문은 막대 d+1부터 유효하다.
- **호가 가능 조건**: 막대 d의 bid > 0, ask > bid, ask − bid ≤ 12틱, ask − bid ≥ 최소 스프레드 틱(격자), bsz > 0, asz > 0, 유동성 게이트 통과. 아니면 그 구간은 호가를 내지 않는다.
- **호가**: 매수 P_b = bid_d, 매도 P_a = ask_d에 최우선 호가로 합류한다(대기열 맨 뒤). 크기: 매수 min(Q, L·Q − q), 매도 min(Q, L·Q + q)(q = 재고, Q = 100, L = 재고 한도 랏 수). 크기가 0 이하이면 그쪽은 내지 않는다. 롱 전용이면 매도 크기는 min(Q, q).
- **재호가 방식**: (reset) 확인 주기마다 미체결을 취소하고 새로 낸다(브리프의 규칙, 대기열 위치를 잃음). (event) 1초마다 확인하고, 내 가격이 현재 최우선이면 유지(대기열 위치 유지), 최우선이 움직였거나 신호 필터가 걸리면 취소하고 새로 낸다.
- **재고 정체 청산**: |q| = L·Q인 채로 연속 S초(격자)가 지나면 결정 d에서 1랏(Q주)을 시장가로 줄인다. 줄이고 나면 타이머를 0으로 한다.
- **청산(d_f)**: 모든 주문 취소, 남은 재고 전량 시장가. 밤샘 보유 없음. 목표가·손절은 없다.
- **신호 필터**(격자 차원, 켜면 해당 쪽 호가만 뺀다): OBI_d = (bsz_d − asz_d)/(bsz_d + asz_d). OBI ≤ −θ_o이면 매수 호가 없음, ≥ +θ_o이면 매도 호가 없음. 변동성 휴지: |mid_d − mid_{d−15}| ≥ 3 σ₁ √15이고 ≥ 1틱이면 60초간 호가 없음, σ₁ = 직전 1,800초 1초 mid 변화의 제곱평균 제곱근(첫 1,800초는 비적용). 체결 흐름 불균형: 직전 10초의 비단주 체결에서 FI = (vol_ask − vol_bid)/(vol_ask + vol_bid)(합이 300주 이상일 때만), FI ≥ +0.6이면 매도 호가 없음(매수 압력), FI ≤ −0.6이면 매수 호가 없음.

## 7. 체결 모델과 체결 가격
**지정가(매수 P_b, 호가 시점 대기열 앞 수량 A = θ · bsz_d)가 막대 u에서 체결되는 규칙**(매도는 대칭: bid↔ask, min↔max, vol_bid↔vol_ask, 부등호 반대). bsz는 주식 수.
- **모델 S(엄격, 하한)**: ask_min_u ≤ P_b이면 그 막대에서 전량 체결.
- **모델 T(접촉, 상한)**: S의 조건 또는 (px_min_u > 0이고 px_min_u ≤ P_b)이면 전량 체결.
- **모델 Q(대기열, 판정 모델, θ = 1)**: 막대마다 순서대로
  1. ask_min_u ≤ P_b이면 남은 수량 전량 체결(교차).
  2. 아니고 0 < bid_max_u < P_b이면(시장 bid가 내 가격 아래로 내려가 내가 최우선) 앞 수량은 0이고 크레딧 = vol_bid_u − vol_bid_odd_u를 남은 수량에 적용(부분 체결).
  3. 아니고 bid_min_u = bid_max_u = P_b이면 크레딧 = vol_bid_u − vol_bid_odd_u를 먼저 앞 수량 A에서 빼고, 남은 크레딧을 내 수량에 적용(부분 체결).
  4. 그 밖에는 크레딧 0(시장 bid가 위로 벗어나 있거나 초 안에서 바뀜: 보수적).
  단주 체결(`I`)은 대기열을 줄이지 않는다. 앞 수량의 취소로 인한 감소는 무시한다(보수적). **event 방식에서 주문이 유지되면 앞 수량 A는 막대마다 줄어든 값을 이어서 쓴다**(내 뒤에 들어온 주문은 영향 없음). reset 방식은 주기마다 A를 새로 잡는다.
- **모델 Q50, Q25(민감도)**: Q에서 θ = 0.5, 0.25. 판정에 쓰지 않는다.
- **체결 가격**: 지정가 체결은 그 지정가(가격 개선 없음). 가격 개선 호가는 1초 막대에 가격별 체결 수량이 없어 체결을 검증할 수 없으므로 시험하지 않는다.
- **시장가(정체·마감 청산)**: 결정 d에서 낸 시장가는 막대 d+1에서 체결. 매도 가격 = min(bid_d, bid_min_{d+1}), 매수 가격 = max(ask_d, ask_max_{d+1}).
- 한 막대 안의 사건 선후는 알 수 없으므로 극값과 합계만 쓰고 순서를 가정하지 않는다.

## 8. 비용 시나리오와 손익 회계
| 시나리오 | 시장가 수수료 | 지정가 체결 | 한도 벌금 | 용도 |
|---|---|---|---|---|
| **R(실제, 판정)** | $0.003/주 + 반대 호가 가격 | 수수료·리베이트 0 | — | 판정 |

- 결정과 체결은 비용에 의존하지 않으므로 같은 체결 경로에 시나리오를 사후 적용한다. C의 벌금은 크기 제한으로 발생하지 않는다(0건 보고).
- **현금 손익** = Σ(매도 체결가 × 수량) − Σ(매수 체결가 × 수량). 일 마감 재고 0이므로 평가손익은 없다. **일간 순손익** = Σ_i(현금 손익_i − 수수료 + 리베이트).
- **손익 분해**: 체결 j의 부호 수량 s_j, 가격 p_j, 기준 mid m_j(결정 시점 d의 (bid_d + ask_d)/2). 엣지_j = s_j · (m_j − p_j), 재고 손익 = −Σ_j s_j · m_j. 현금 손익 = Σ엣지 + 재고 손익(정확히 성립, 합성 테스트 M5). 엣지는 지정가(스프레드 포착)와 시장가(스프레드 지불)로 나눠 보고한다.
- **마크아웃**: 지정가 체결 k ∈ {1, 5, 30, 60}초 뒤 mid와 체결가의 차이 × (매수 +1, 매도 −1). **음수가 역선택이다.**
- **손익분기 리베이트**: (−순손익)/지정가 체결 수량(주당 달러, 양수면 "필요 없음").
- SEC·FINRA 수수료(매도), 공매도 대여 비용과 가능 여부, 소액 계좌 수수료는 모형 밖이며 한계에 적는다.

## 10. 통계 방법
- **일간 계열**: 종목 합산 일간 순손익(달러). 거래일 전부가 관측이다(그날 체결이 없어도 0). 샤프 = 평균 / 표준편차(ddof = 1) × √252, **무위험이자율 없이**.
- **CI**: 순환 블록 부트스트랩, **블록 10거래일**, 10,000회, 백분위 구간, 시드 12. 주 판정 95%.
- **Deflated Sharpe**: Bailey & López de Prado, N = 실제 시험 설정 수, 귀무 시행 분산 1/(T_d − 1), 왜도·첨도 보정 포함. 후보의 홀드아웃에 계산한다.
- **병기 지표(R·R+·C를 함께)**: 연율 순 샤프와 95% CI, 일평균 순손익과 Newey-West t(5시차), 거래당 순손익(체결 수량당 ¢, 체결 금액당 bp), 최대낙폭과 칼마, 소르티노, 왜도·첨도·최악의 하루, 승률과 평균 이익/평균 손실, profit factor, 오메가, 거래 빈도, 슬리피지(시장가 체결의 mid 대비 불리분), 체결률, 평균 |재고|·최대 재고, 알파·베타(일간 순손익을 시장 대용 수익률에 회귀), 연도별 순손익.
- **시장 대용 수익률**: 해당 유니버스 종목의 시가-종가 동일가중 수익률(막대의 첫·마지막 mid).

## 11. 판정 문장 (홀드아웃, 후보 1개, 95% CI, Q·R)
후보의 홀드아웃 순 샤프 점추정 x와 95% CI [a, b]로 세 갈래 중 하나로 판정한다(SR\* = 0.5, MDE = 2.09). **모든 문장 끝에 "(대기열 모델이 앞 수량의 취소를 무시한 보수적 체결 가정이고, 지정가 리베이트가 없는 실제 비용 가정이며, 개발 구간에서 설정 N개 중 1개를 골랐다. 같은 시장·기간의 일간·월간 수익률 결과를 이미 본 구간, 탐색적 증거)"를 붙인다.**
- **(a) 남는다**: a > 0이고 x ≥ 0.5. "개발 구간에서 선택한 시장조성 설정은 2021~2026년 홀드아웃에서 비용 후에도 경제적으로 의미 있는 수준으로 남는다(순 샤프 x, 95% CI [a, b]). 선택한 설정은 [설정]이다." x < 2.09이면 "다만 이 표본(5.72년)으로 검출 가능한 최소 샤프(2.09)보다 작아 확정적이지 않다."를 붙인다.
- **(b) 못 미친다**: b < 0.5. "…경제적으로 의미 있는 수준(샤프 0.5)에 못 미친다(순 샤프 x, 95% CI [a, b])."
- **(c) 확정 불가**: 그 외. "이 표본으로는 …수익이 경제적으로 의미 있는 수준인지 확정할 수 없다(순 샤프 x, 95% CI [a, b], 검출 가능한 최소 샤프 2.09)."
- **별도 보고 줄(판정과 무관)**: "CI 하한 > SR\*: 예/아니오." "개발 샤프 대비 홀드아웃 샤프(선택 낙관 정도)." "체결 모델 S, Q50, Q25, T와 시나리오 R+, C의 순 샤프." "손익분기 리베이트." "B0와 A_naive의 홀드아웃 순 샤프(기술통계)."
- 보조 분석, 격자 결과, 민감도, 비교군은 판정을 바꾸지 않는다.

## 20. 알려진 한계
1. **시도 횟수 12, N ≤ 69.** 후보가 통과해도 여러 시도 중 하나라는 점을 감안해야 한다.
2. **1초 해상도**: 같은 막대 안의 사건 선후를 모른다. 규칙은 극값과 합계만 쓴다.
3. **대기열 모델**: 앞 수량의 취소 감소를 무시(보수적)하고 단주를 제외한다. 실제 체결은 S와 T 사이 어딘가다. Q50·Q25는 거친 대용이다. 시장조성은 체결 가정이 결과를 좌우하므로 백테스트의 "된다"는 잠정이고 "안 된다"가 더 믿을 만하다.
4. **지연 가정**: 주문은 결정 후 1초 뒤 유효하고 시장가는 불리한 쪽 가격으로 체결한다.
5. **비용**: R은 지정가 리베이트 0의 중립 가정이다. SEC·FINRA 수수료, 거래소별 요금, 소액 계좌의 실제 수수료는 모형 밖이다.
6. **공매도**: 양방향 설정은 공매도가 가능하고 대여 비용이 0이라고 가정한다. 소형주에서는 비현실적일 수 있어 롱 전용을 격자에 넣었다.
7. **호가 깊이 없음**: 최우선 수량만 알고, 가격 개선 호가와 깊은 호가는 시험하지 않는다.
8. **종목 효과**: 해마다 10개씩 쓰므로 개별 종목의 실적 발표·뉴스 충격이 결과에 크게 반영된다(B10으로 극단일을 보고). 거래 정지·급변동 중의 체결 가정이 안 맞을 수 있다.
9. **종목 선정 편향**: 직전 연도 12일 통계로만 고르지만 12일 표본은 작다. 연중 합병·종목 코드 변경으로 사라지는 종목은 대체하지 않으므로 후반에는 종목 수가 줄 수 있다.
10. **선택 편향**: 개발 샤프는 낙관적이다(1절). 홀드아웃이 이를 걸러 낸다.
11. **검정력**: 진짜 샤프가 0 근처이거나 1 이하이면 (c)가 많다. 홀드아웃 5.72년의 MDE가 2.09다.
12. **개발 2.00년**: 격자 선택이 거칠다. 설정 간 개발 샤프 차이 1 이하는 노이즈일 수 있다(SE 약 0.7).
13. **오염**: 같은 시장·기간의 일간·월간 결과와 연구 1의 결과를 알고 설계했다(9절).
14. **라운드랏 정의**: U1은 2018-06-13 하루, 두 종목에서만 확인했다. 이후 라운드랏 정의가 바뀌었을 가능성이 있고 단주 체결 분류와 표시 수량의 의미가 달라질 수 있다. 막대는 `sizeshares`(주식 수)를 쓴다.
15. **데이터 의존**: WRDS complete_nbbo의 NBBO 계산과 ctm의 체결 코드에 의존한다. 정규장 호가 NULL이 한쪽 호가 없음이면 이월 상태가 낡을 수 있다.
16. **용량**: 100주·10종목이라 규모를 키울 때의 영향(대기열 점유, 시장 충격)은 이 연구 밖이다.
17. 이 문서는 연구 계획이며 투자 자문이 아니다. 소액 계좌 집행, 세금, 증거금, 거래소 접근은 모형 밖이다.
