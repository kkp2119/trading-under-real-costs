## E1-45 메모: 샤프 SE 식
- **SPEC 식**: 1절 "SE ≈ √((1 + SR²/2)/연수)"와 그로부터 얻은 MDE = √(7.84/(연수 − 3.92)) = 2.09, 그리고 검정력 표.
  - 이것은 Lo(2002)의 iid 식 SE(ŜR) = √((1 + SR²/2)/n)에 SR = 연율, n = 연수를 넣은 것이다.
  - 일간 관측을 연율화하면 SR_일 = SR/√252, n = 252·연수이므로 SE = √((1 + SR²/(2·252))/연수)가 된다.
- **합성 점검**(iid 정규 일간, T = 1,441, 4,000회): 참 SR 0, 1, 2에서 연율 샤프 표준편차가 0.417, 0.420, 0.419였다. SPEC 식은 0.418, 0.512, 0.724를 주고, 일간 식은 0.418, 0.419, 0.420을 준다.
- **그 결과**:
  - 일간 식의 MDE는 1.17이다.
  - 검정력 표 P(a)는 SR 0.5: 0.224(SPEC 0.128), SR 1.0: 0.667(0.496), SR 2.0: 0.998(0.915).
  - P(b)는 SR −1.0: 0.948(0.900)이다.
  - 따라서 M9의 "부트스트랩 합성 시뮬로 표 ±0.05"는 SPEC 표에 대해 실패한다.
- **판정 자체에는 영향이 없다**: 판정 (a)/(b)/(c)는 블록 부트스트랩 CI로 정하므로 식과 무관하다. 바뀌는 것은 1절의 설명 수치(문턱 약 1.0 → 약 0.82), 판정 문장의 MDE 숫자(2.09), "x < MDE이면 확정적이지 않다" 문구가 붙는 범위, M9 기준이다.
- 실제 시장조성 일간 손익은 두꺼운 꼬리·자기상관이 있을 수 있어 부트스트랩 SE가 iid 정규보다 크다. 그래서 SPEC 수치는 보수적인 쪽이다.
- **선택지**:

- 연구 10·11도 같은 MDE 식(stats.mde)을 썼다. 기록만 하며, 이미 끝난 판정은 바꾸지 않는다.
