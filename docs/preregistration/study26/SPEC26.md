## 2. 격자와 선택 (연구 12와 같음)
- **1단계:** B0(재호가 5초, L 3, stale 60초, 양방향, 최소 스프레드 2틱, 09:45–15:55)와 대안 18개.
- **2단계:** 개발 순 Sharpe가 B0 + 0.5 이상인 대안을 채택하고, 채택된 값을 모은 C_all과 하나씩 되돌린 설정을 돌린다.
- **선택 필터:**
  - (i) 해마다 순 Sharpe > 0. 2015–2020의 **여섯 해 모두**에 적용한다(연구 12의 "2019·2020 둘 다"를 같은 뜻으로 늘린 것).
  - (ii) Q50 순 Sharpe > 0
  - (iii) 종목·일당 체결 1회 이상, 참여율 1% 미만
  - (iv) 이웃 설정의 순 Sharpe ≥ 0
- **선택:** 필터를 통과한 설정 가운데 개발 순 Sharpe(Q, R)가 가장 높은 것. 동률 규칙은 연구 12와 같다.
- **게이트 G1:** 연구 12와 같다(순 Sharpe ≥ 1.0, 호가 가능 비율 ≥ 0.90 등).
- **위약 검정(obi, fi 각 200회):** 연구 12와 같이 돌린다.
- **체결과 비용:** 판정은 대기열 모델 Q(θ = 1)와 비용 R(시장가 0.3¢/주, 지정가 0). S, T, Q50, Q25와 R+는 함께 보고한다.
