## 2. 주문 설계와 비용 (연구 17·18과 같음)
- 종목·일당 부모 주문 20건, 1,000주, 기한 300초다. 방향을 정하는 방식도 같다.
- 비용: 시장가 0.3¢/주, 지정가 0
- **체결 가정:** L3D1(주, 가장 엄격), L0D0(보조)
- **비교 대상:** S0(시장가), S2i(단순 대기), E*, C3(연구 17의 스프레드 전환)

## 3. 신호 (데이터를 보기 전에 고정)
- **기준 두 가지:**
  - SPY 기준: s_t = ln(종목 중간값) − ln(SPY 중간값)
  - 자기 가격 기준: s_t = ln(종목 중간값)
- **z_t = (s_t − m_t) ÷ σ_t.** m_t와 σ_t는 직전 30분의 5초 격자 표본으로 계산한다. 연구 20의 신호 코드와 해석을 그대로 쓴다(유효 표본 360개, σ 하한 1bp).
- **불리함 점수 a_t:** 매수 주문은 a_t = −z_t, 매도 주문은 a_t = +z_t다.
  - a_t가 크다는 것은 종목이 기준보다 우리에게 유리한 쪽으로 벗어나 있다는 뜻이다. 가격이 되돌아가면 우리에게 불리해진다.
- **결정 시점:** E*와 같은 5초 간격이다. 남은 수량이 있을 때만 쓰고, 기한 시점은 뺀다. 결정 막대 끝까지의 정보만 쓴다.
- **신호가 없는 시점:** 창이 차기 전, 호가가 유효하지 않은 시점, SPY 파일이 없는 날에는 E*와 똑같이 행동한다.

## 4. 실행 규칙 후보
| 번호 | 이름 | 규칙 |
|---|---|---|
| G0 | E* | 동결 규칙 그대로 (기준) |
| G1 | 조기 체결 | a_t ≥ z_th이면 남은 수량을 그 막대 끝 호가에 시장가로 처리한다(L3D1이면 D1 벌점) |
| G2 | 대기 유지 | a_t ≤ −z_th이면 E*의 좁은 스프레드 즉시 체결을 건너뛰고 계속 기다린다 |
| G3 | 둘 다 | G1 + G2 |

- **격자 12개 (고정):** 기준 {SPY, 자기 가격} × z_th {1, 2} × 규칙 {G1, G2, G3}
- **선택 규칙:** 개발 구간(기존 유니버스 2015–2020, L3D1)의 평균 IS가 가장 낮은 후보를 A*로 정한다.
  - 그 후보가 G0보다 0.02¢ 넘게 낮지 않으면 A* = G0이다. 이때 Q2는 "개발에서 개선 없음"으로 끝내고 봉인 검정은 H1만 한다.
  - 후보끼리 0.02¢ 안의 동률이면 95번째 백분위 IS가 낮은 쪽, 그다음 발동 비율이 낮은 쪽을 고른다.
- **엔진:** 연구 18의 조기 체결·대기 유지 경로를 고치지 않고 쓴다. 예측 확률 자리에 신호로 만든 발동 표시를 넣는다. 그대로 쓸 수 없으면 질문 목록에 올린다.
  - 회귀 테스트: G0가 연구 17·18의 E* 개발 값을 소수 3자리까지 재현해야 한다.

## 5. 봉인 테스트 가설과 판정 (한 번만 실행)
- **H1 (재현):** 새 유니버스 C에서 E* − S0 < 0 (L3D1, ¢/주)
- **H2 (개선):** 새 유니버스 C에서 A* − E* < 0 (L3D1). A* = G0이면 H2는 없다.
- **검정:** 일 단위 순환 블록 부트스트랩(21일, 10,000회, seed 22), 단측. 남아 있는 가설(1 ~ 2개)에 Holm을 적용한다(전체 α 0.05).
- **보조 (판정 아님):**
  - L0D0 결과, 연도별 결과, 95번째 백분위 IS의 차이
  - A* − S0, A* − C3, A* − S2i
  - 발동 비율: 결정 시점과 주문 가운데 신호가 행동을 바꾼 비율
  - 신호의 예측력: 발동 뒤 60초와 180초의 중간값 변화(우리에게 불리한 방향이 양수, bp)의 평균과 CI
  - 지연 점검: 결정은 막대 t, 실행은 막대 t + 1의 호가
  - 2025-10-31까지와 2025-11-03부터로 나눈 결과
- **검정력:** 봉인 데이터를 열기 전에 개발 구간의 일 단위 분산으로 H1·H2의 MDE를 계산한다. MDE가 개발 효과보다 크면 "검정력 부족"으로 미리 표시한다.
