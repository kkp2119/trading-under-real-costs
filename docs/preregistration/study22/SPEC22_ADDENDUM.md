# SPEC22 추가 문서 (2026-11-13 작성: spec22 커밋 뒤, 개발 실행 전)

이 내용을 `research22/SPEC22_ADDENDUM.md`로 그대로 복사하고 동결 커밋에 넣는다.
우선순위는 이 문서 > SPEC22_ANSWERS > SPEC22다.

- **작성 시점:** 후보의 IS와 손익을 하나도 계산하기 전이다. 본 것은 회귀 테스트의 S0, S2i, E*, C3 개발 값뿐이고, 이 값은 연구 17·18에서 이미 본 값이다.
- **바꾸지 않는 것:** H1, H2, Holm, 후보 12개, 선택 규칙, 결과별 문장, 예측. 아래 D1 ~ D3은 모두 보조 분석이다.

## D1 · 대조 실행: 부호를 뒤집은 신호 (판정 아님, 후보 아님)
- **내용:** A*가 G0가 아닐 때, A*와 같은 기준·기준값·규칙에서 불리함 점수 a_t의 부호만 뒤집어 한 번 더 돌린다. 개발 실행과 봉인 실행 모두에서 한다.
- **이유:** 개선이 신호의 정보에서 오는지, 즉시 체결의 횟수만 바뀌어서 오는지 가르기 위해서다.
  - 개발 구간의 L3D1에서 S2i(3.112¢)가 E*(3.148¢)보다 조금 싸다. 그래서 신호와 무관하게 즉시 체결을 줄이기만 해도 E*보다 싸질 수 있다.
  - 정보가 있다면 뒤집은 신호는 E*보다 나빠지거나 A*보다 뚜렷하게 나빠야 한다.
- **보고:** 대조 − E*와 A* − 대조의 짝 차이와 95% CI(L3D1, L0D0)
- **취급:** A* 선택에 넣지 않는다. 시행 수에 세지 않고 DEVIATIONS22에 적는다.

## D2 · 봉인 실행의 비교 대상에 C3를 넣는다
- **이유:** SPEC22 5절의 보조 항목 "A* − C3"를 내려면 봉인 실행이 C3를 돌려야 한다.
- **A* = G0일 때:** C3 − E*를 보조로 낸다(연구 17의 스프레드 전환을 세 번째 종목 묶음에서 다시 보는 것). 판정에 쓰지 않는다.

## D3 · 봉인 실행의 예측력 표
- **내용:** 봉인 실행에서도 개발 실행과 같은 표 전부를 낸다(기준 2개 × 기준값 2개 × 조건 2개, 60초와 180초).
- **예측표 다섯째 줄의 판정:** DEVIATIONS22 1절 12번 그대로다(A*의 기준과 기준값, A* = G0이면 개발 결과 파일의 `prediction_setting`).
