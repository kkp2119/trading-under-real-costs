## 2. 주문 설계와 비용 (연구 15·16과 같음)
- 종목·일당 부모 주문 20건, 1,000주, 기한 300초, 매수·매도 방향은 연구 15와 같은 방식으로 정한다.
- 비용 시나리오 R: 시장가 0.3¢/주, 지정가 0

  - L0D0 (보조): 원래 엔진 그대로
- **비교 대상:** S0(시장가 즉시), S1(TWAP), S2i(1¢ 안쪽 단순 대기), E*

## 3. Q2 후보 규칙 (데이터를 보기 전에 고정, 6개)
| 번호 | 이름 | 규칙 |
|---|---|---|
| C0 | E* | 동결 규칙 그대로 (기준) |
| C1 | 단순 대기 | S2i |
| C2 | 변동성 전환 | vol_pre가 낮음 칸(< 4.68 bp, 16-E 기준값)이면 S2i, 아니면 E* |
| C3 | 스프레드 전환 | 도착 스프레드 ≤ 4¢이면 S2i, 아니면 E* |
| C4 | E* + 손절 | 대기 중 중간값이 도착 때보다 3틱 이상 불리하게 움직이면 남은 수량을 즉시 시장가로 처리 |
| C5 | 변동성 전환 + 손절 | C2에 C4의 손절을 붙인 것 |

- 기준값(4.68 bp, 4¢, 3틱)은 위에 적힌 값으로 고정하고 튜닝하지 않는다.
- vol_pre는 연구 16-E와 같은 정의다: 주문 전 30분 동안 1분 중간값 수익률의 표준편차. 최소 10분이 필요하고, 부족하면 E*로 처리한다.
- **고르는 규칙:** 개발 데이터(기존 유니버스 2015–2020, L3D1)에서 평균 IS가 가장 낮은 후보를 A*로 정한다.
  - 0.02¢ 안의 동률이면 95번째 백분위 IS가 낮은 쪽, 그다음 규칙 수가 적은 쪽을 고른다.
  - A*가 C0(E*)이면 Q2는 "개발에서 개선 없음"으로 끝내고 봉인 검증은 Q1만 한다.
- **엔진 확장:** C4·C5의 손절은 새 코드다.
  - 합성 데이터 테스트를 먼저 통과해야 한다.
  - 회귀 테스트: 확장 엔진으로 돌린 C0·C1·S0가 연구 16-D 결과를 소수 3자리까지 재현해야 한다.

## 4. 봉인 테스트 가설과 판정 (한 번만 실행)
- **H1 (Q1):** 새 유니버스에서 E* − S0 < 0 (L3D1)
- **H2 (Q2):** 새 유니버스에서 A* − E* < 0 (L3D1). A* = C0이면 H2는 없다.
- **검정:**
  - 일 단위 순환 블록 부트스트랩, 블록 21일, 10,000회, seed 17
  - 단측 α = 0.05, H1·H2에 Holm 보정
  - 판정: 보정된 CI 상한 < 0이면 "확인", 아니면 "확인 안 됨"
- **보조 (판정 아님):**
  - L0D0 결과
  - A* − S2i, E* − S1
  - 95번째 백분위 IS
  - 연도별 결과
  - 16-E 방식의 3 × 3 칸 분해 (기준값은 개발 구간 것)
- **검정력:** 데이터를 열기 전에 개발 구간의 일 단위 분산으로 H1·H2의 최소 탐지 효과(MDE, 검정력 80%)를 계산한다.
  - H2의 MDE가 개발 구간 효과(A* − E*)보다 크면, H2를 "검정력 부족"으로 미리 표시한다.
