## A. 유니버스 선정 (1절)

## C. Q2 후보 규칙 (3절, 2단계 전에 답 필요)
12. **C2 vol_pre.** 16-E 정의를 쓴다: 시작 1초 전부터 1분 간격 31점, 유효 1분 수익률 10개 이상, 1분 bp. 16-E의 실제 1/3 분위수는 4.67696 bp이고, 계획의 4.68은 이를 반올림한 값이다. 두 가지를 알려 달라.
    - 기준값으로 4.68과 4.67696 중 어느 것을 쓸지
    - "낮음 칸"이 `≤`인지 `<`인지. 16-E 칸은 `≤ c1`이었고, 원문은 "<"다.
13. **C3 "도착 스프레드 ≤ 4¢".** 막대 s의 ask − bid ≤ 4¢로 읽는다(같음 포함).
14. **C4 손절.**
    - "중간값이 도착 때보다 3틱 이상 불리"는 매수라면 mid ≥ 도착 mid + 3¢로 읽는다.
    - **확인 시점:** 매초 볼지, 5초 결정 시점에만 볼지 알려 달라.
    - **시장가 체결:** 엔진의 E1·기한 시장가와 같이 그 막대의 최우선 호가에 체결하고, D1을 적용하는 것으로 읽는다.
    - 매초 확인하면 같은 막대의 지정가 체결과 손절 가운데 어느 것이 먼저인지도 정해야 한다.
15. **C5.** "C2에 C4의 손절"은 vol_pre가 낮으면 S2i + 손절, 아니면 E* + 손절로 읽는다. 원문 그대로라면 S2i 쪽에도 손절이 붙는다. 맞는지 알려 달라.
16. **동률 판정 "규칙 수".** C0 1, C1 0, C2·C3 2, C4 2, C5 3으로 세면 되는지 알려 달라.

## D. 봉인 테스트 (4절)
17. **Holm 보정과 "보정된 CI".**
    - **구현안:** 부트스트랩으로 각 가설의 한쪽 p값을 구하고 Holm 순서로 판정한다. 보고용 CI 상한은 첫 가설 97.5%(한쪽 α 0.025), 둘째 95%로 한다.
    - 원문의 "보정된 CI 상한 < 0"과 같은 뜻인지 알려 달라.
    - H2가 없으면(A* = C0) H1은 α 0.05인지도 알려 달라.
18. **H2에서 A* = C1(S2i)인 경우.** H2는 S2i − E* < 0이다. 그대로 두면 되는지 확인만 부탁한다.
19. **보조 3 × 3 분해.** 16-E 기준값(개발)을 그대로 쓴다. adv_prior의 "같은 해 유니버스 안 직전 20거래일"은 새 유니버스에도 같은 방식으로 적용한다.
