## 3. 예측 모델 (데이터를 보기 전에 고정)
- **결정 시점, 목표값, 평가 지표:** 연구 18과 같다(5초 간격, 60초 안의 첫 중간값 변화가 불리하면 1).
- **입력 6개:**

  6. 자기 가격 기준 불리함 점수 a_t (같은 방식)
  - 신호가 없는 시점의 5번과 6번은 0으로 둔다.
- **모델:** 표준화한 로지스틱 회귀, L2 C = 1.0 고정. 학습 구간에서 한 번만 적합하고 계수를 동결한다.
- **비교 모델:** 연구 18의 동결 모델(입력 4개)을 같은 시점에서 함께 채점한다.

## 4. 실행 규칙 후보
- **규칙과 격자:** 연구 18과 같다. R0(E*), R1(조기 체결, p ≥ p_hi), R2(대기 유지, p ≤ p_lo), R3(둘 다). p_hi ∈ {0.60, 0.65, 0.70, 0.75}, p_lo ∈ {0.30, 0.35, 0.40}, 후보 19개.
- **선택 규칙:** 검증 구간(2019–2020, L3D1)의 평균 IS가 가장 낮은 후보를 A*로 정한다.
  - 그 후보가 R0보다 0.02¢ 넘게 낮지 않으면 A* = R0이다. 이때 Q2는 "개발에서 개선 없음"으로 끝낸다.
  - 후보끼리 0.02¢ 안의 동률이면 95번째 백분위 IS가 낮은 쪽, 그다음 발동 비율이 낮은 쪽을 고른다.
- **엔진:** 연구 18과 22의 엔진 경로를 고치지 않고 쓴다.

## 5. 봉인 테스트 가설과 판정 (한 번만 실행)
- **H1 (예측):** 새 유니버스 D에서 합친 모델의 AUC > 0.5
- **H2 (개선):** 새 유니버스 D에서 A* − E* < 0 (L3D1, ¢/주). A* = R0이면 H2는 없다.
- **검정:** 일 단위 순환 블록 부트스트랩(21일, 10,000회, seed 23), 단측. 남아 있는 가설(1 ~ 2개)에 Holm을 적용한다(전체 α 0.05).
- **보조 (판정 아님):**
  - AUC(합친 모델) − AUC(연구 18 모델)과 95% CI
  - E* − S0 (네 번째 종목 묶음에서의 재현), L0D0 결과, 연도별 결과, 95번째 백분위 IS의 차이
  - A* − C3, A* − S2i
  - 대조 실행: A*가 R0가 아니면, 예측 확률을 1 − p로 뒤집어 한 번 더 돌린다(연구 22의 D1과 같은 목적)
  - 지연 점검(결정 t, 실행 t + 1), 2025-10-31까지와 2025-11-03부터로 나눈 결과
- **검정력:** 봉인 데이터를 열기 전에 검증 구간의 분산으로 H2의 MDE를 계산한다.
