# SPEC23 답변 (2026-11-13, Kyle)

이 답변은 신호, IS, 손익을 하나도 계산하기 전에 썼다.

- **A1 · WRDS:**
  - 유니버스 D 선정에 쓴 조회를 승인한다(연구 22와 같은 범위).
  - 유니버스 D 종목의 TAQ 1초 막대 수집(2021-01-04 ~ 2026-11-10)을 허락한다. 수집 방식은 연구 22와 같다(여유 공간이 12 GiB 아래로 내려가면 멈춤).
- **A2 · FWRD 2025:** 기본값대로 2025-06-16부터의 138일을 뺀다(연구 22의 TSE와 같은 처리).
- **A3 · 모델 입력을 9개로 늘린다 (SPEC23 3절의 "입력 6개"를 바꾼다):**
  - 1 ~ 6번은 SPEC23 그대로다.
  - 7번 체결 불균형(30초), 8번 체결 강도(60초), 9번 둘의 곱을 더한다. 정의는 질문 목록 20번의 기본값 그대로다.
  - 이유: 실제로 체결된 거래량과 그 방향은 지금까지 예측에 쓰지 않은 정보다.
- **A4 · 체결 수량의 단위 확인:** 질문 목록 19번의 기본값대로 한다.
  - 유니버스 D 수집 뒤의 품질 확인에서 2025-10-31까지와 2025-11-03부터의 체결 수량 단위를 종목·일별로 확인한다.
  - 100배 차이가 보이면 멈춰서 보고한다. 확인 전에는 보정하지 않는다.
- **A5 · 학습 코드:** 연구 18의 학습 순서를 새 파일에 그대로 옮긴다. 연구 18의 파일은 고치지 않고, 동결 모델 파일도 덮어쓰지 않는다.
  - 회귀 테스트: 새 코드에 연구 18의 입력 네 개만 넣어 학습하면 연구 18의 동결 계수가 재현돼야 한다.
- **A6 · A* 선택:** 가장 좋은 후보가 R0보다 0.02¢ 넘게 낮지 않으면 A* = R0이다. R0는 후보끼리의 동률 비교에 들어가지 않는다(연구 22와 같음).
- **A7 · 종목 수:** N = 20이다.
- **A8 · 질문 목록의 나머지 기본값:** 모두 승인한다. 보통주가 아닌 종목은 그대로 두고, 두 해 이상 뽑힌 종목은 허용한다. 보조 분석에 보통주만의 결과를 더한다.
