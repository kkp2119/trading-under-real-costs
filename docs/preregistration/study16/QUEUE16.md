## 2. 줄 위치 모델 Q(x)
- **엔진:** 연구 12 엔진의 Q 모델을 그대로 쓴다. 우리 지정가 주문이 그 가격에 들어갈 때 줄 앞 물량을 아래처럼 정한다.
  - **줄 앞 물량 = x × (그 시점 그 가격에 보이는 물량)**
  - x = 1이면 기존 Q 모델이고, x = 0이면 줄 맨 앞이다.
- **나머지 규칙:** 엔진의 기존 규칙(줄 앞 물량이 체결로 줄어드는 방식, 취소 처리, 가격이 우리 호가를 뚫고 지나갈 때의 처리, 부분 체결)은 바꾸지 않는다.
  - 엔진이 취소를 어떻게 처리하는지(보이는 물량이 줄 때 우리 앞이 줄어드는지)는 코드에서 확인해 보고서에 한 줄로 적는다.
- **x 값:** 0, 0.1, 0.2, …, 1.0 (11개)
- **참고로 함께 보고:** 기존 T 모델 결과(dev_daily.csv의 B0|T|R)와 Q(0)의 차이

## 3. 비용 시나리오
- **R (주):** 시장가 0.3¢/주, 지정가 0
- **R+ (보조):** 시장가 0.3¢/주, 지정가 체결 시 리베이트 0.2¢/주
  - 거래소가 호가를 대는 쪽에 주는 리베이트이고, 초고속 시장 조성자들이 실제로 받는 구조다.
  - 체결 결과는 같고 비용 계산만 다르므로, 같은 체결로 다시 계산해도 된다.

## 4. 지표 (x와 시나리오마다)
- 순손익($), 주당 손익(¢) = 순손익 / (지정가 주식 수 + 시장가 주식 수) × 100
- 샤프: 일별 순손익의 평균 / 표준편차 × √252
- 지정가 체결 수, 지정가 주식 수, 시장가 주식 수, 손실 일 비율
- **본전 위치 x\***: 주당 손익이 0이 되는 x. 이웃한 두 x 사이에서 선형 보간한다.
  - x = 0에서도 음수면 "줄 맨 앞에서도 본전 아님"이라고 적는다.
- **합격선 위치 x\*\***: 샤프가 0.5가 되는 x. 같은 방식으로 구한다.
- **결과를 본 뒤 x 격자나 모델을 바꾸지 않는다.** 이상한 점은 DEVIATIONS16.md에 적기만 한다.
