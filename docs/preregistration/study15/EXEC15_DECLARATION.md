# 연구 15-E 선언: 머신러닝으로 체결 비용 줄이기

작성 2026-10-29 20:13 ET · 시뮬레이션을 돌리기 전에 작성 · 기준 커밋 6f5312c
누적 시도 횟수: 436 + 격자 216 = **652**

배경 (Kyle): 직접 시장조성은 모든 변형에서 손실이었다(3단계, R1). 그러나 머신러닝이 고른 지정가 체결은 무작위보다 덜 당했다(참고 분석). 그래서 같은 모델을 "어차피 사고팔아야 하는 주문을 더 싸게 체결하는 데" 쓴다. 이길 기준은 0이 아니라 단순한 체결 방법의 비용이다.

아래 1~6은 Kyle의 지시를 그대로 옮긴 것이다. 구현 세부(지시에 없던 결정)는 DEVIATIONS15.md 20절에 시뮬레이션 전에 적는다.

## 1. 과제 (부모 주문)
- 종목-일마다 부모 주문 20개를 만든다. 방향은 매수·매도 반반 무작위, 시드는 15+날짜.
- 수량 1,000주, 기한 300초. 시작 시각은 9:35:00–15:53:55의 5초 결정 격자에서 무작위로 정한다. 반일장은 마감 막대 −61 전에 기한이 끝나도록 같은 방식으로 정한다.
- 부모 주문은 서로 독립으로 시뮬레이션한다(시장 충격은 모델링하지 않는다).
- 참고용 민감도(선택에 쓰지 않음): 300주·60초.

## 2. 비용 지표
- 실행 부족분(IS, 센트/주) = 방향 × (평균 체결가 − 도착 mid) + 수수료.
- 도착 mid는 시작 막대 끝의 mid다. 수수료는 시나리오 R(시장가 0.3¢, 지정가 0)이고, R+(지정가 −0.2¢)도 함께 보고한다.
- 시장가는 최우선 호가 가격으로 체결한다. 호가 잔량을 넘는 수량도 같은 가격으로 친다. 이는 시장가를 많이 쓰는 방법에 유리한 가정이다(최우선 호가 너머의 깊이 데이터가 없음). 넘은 수량의 비율을 보고한다.

## 3. 방법 (기준 4개 + 머신러닝)
- S0 즉시: 시작할 때 1,000주를 시장가로.
- S1 TWAP: 30초마다 100주씩 시장가로(10번).
- S2 지정가 대기: 남은 수량 전부를 최우선 호가(매수는 bid)에 건다. 가격이 그대로면 대기열 순번을 유지하고(R1 V1 규칙), 가격이 바뀌면 새 최우선 호가로 옮긴다. 기한에 남은 수량은 시장가로 처리한다.
- S2i: S2에 1틱 개선(스프레드 ≥ 3틱이면 bid+1틱, R1 V2 규칙)을 더한다.
- S3 머신러닝 타이밍: 5초마다 3단계 모델의 예측을 쓴다(우리 쪽 = 부모 주문 방향, 거울 입력).
  - 예측 v_h ≥ θ_post이면 S2처럼 지정가로 건다(개선 옵션 on이면 S2i처럼). 아니면 주문을 거둬 기다린다.
  - 서두름 옵션 on: 예측 tk_h ≥ 0이면(가격이 스프레드 이상 도망갈 것으로 예측) 남은 수량을 즉시 시장가로.
  - 기한에 남은 수량은 시장가로 처리한다.
- 체결 판정은 연구 12 Q 모델 그대로다(시험 통과한 simulator15의 fill 함수).

## 4. 격자 (S3만 선택 대상, 지금 고정)
- 모델: 3단계의 6개(릿지 2, LightGBM 4). 폴드별로 이미 학습된 것을 쓴다. 다시 학습하지 않는다.
- h ∈ {5, 30, 60}, θ_post ∈ {−0.5, 0, 0.5}¢, 개선 {off, on}, 서두름 {off, on}
- 설정 수: 6 × 3 × 3 × 2 × 2 = 216개

## 5. 검증과 선택 (3단계와 같은 폴드)
- 폴드 A: 모델 학습 2015–2018 → 2019 / 폴드 B: 모델 학습 2015–2019 → 2020
- 선택 기준: 두 폴드의 평균 IS(R)를 평균한 값이 가장 작은 S3 설정.
- 0.05¢ 이내의 후보가 여럿이면 단순한 쪽을 고른다: 릿지 > LightGBM, 잎 적은 쪽, 개선 off > on, 서두름 off > on, θ_post 큰 쪽.
- 주 비교 기준은 S2(지정가 대기)로 지금 정한다. S0·S1·S2i는 함께 보고한다.

## 6. 테스트 계획 (이번 단계에서는 실행하지 않고 선언만 한다)
- 최종 모델은 고른 설정을 3단계 E 절차로 2015–2020 전체에 다시 학습해 얼린다.
- 2021-01-04부터 봉인 데이터의 마지막 날까지 한 번만 돌린다. 해제 문구는 Kyle이 직접 쓴다.
- 주 판정은 (S3 − S2) 평균 IS 차이(센트/주)로 한다. 날짜 단위 원형 블록 부트스트랩(21일, 10,000번, 시드 15)으로 95% 구간을 낸다.
  - 상한 < 0이면 "머신러닝이 지정가 대기보다 체결 비용을 줄인다"
  - 하한 > 0이면 "더 비싸다"
  - 그 밖에는 "판단 보류"
- 부 지표(판정 없음): S3 − S0, S3 − S1 차이, bp 환산, IS 95분위(꼬리), 지정가로 채운 비율, 지정가 체결의 5초 마크아웃(S3 vs S2), 연도별, 시간대별, 스프레드 구간별.
- 절감 손익과 샤프(부 지표): 일별 절감 손익(달러) = 그날 모든 부모 주문의 (기준 방법 IS − S3 IS) × 체결 수량 합계. 기준은 S2와 S0 각각. 누적 절감 손익 곡선과 연환산 샤프(일별 절감 평균 / 표준편차 × √252)를 낸다. 연도별 절감액과, 이 거래량을 1년 $10억 거래로 환산한 절감액도 함께 보고한다.
